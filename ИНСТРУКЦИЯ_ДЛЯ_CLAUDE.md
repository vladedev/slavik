# Задача: сканы программ ДШИ → редактируемые DOCX

Папка:
- `input/` — исходные PDF
- `prompts/transcribe.md` — правила распознавания страниц (обязательно прочитай)
- `tools/prepare.py`, `tools/assemble.py` — готовые скрипты. Используй их, свой код для этих шагов не пиши.
- `work/` — промежуточные файлы, `output/` — результат

Нужны Python-пакеты: `pip install pypdfium2 pillow beautifulsoup4 python-docx`.
Если pip недоступен или скрипт падает, покажи мне ошибку, не переписывай скрипты.

## Порядок работы
1. **Подготовка (без распознавания).** Для каждого файла задачи запусти
   `python tools/prepare.py "input/<файл>.pdf"`.
   Скрипт найдёт дубли и повторную копию документа в конце, отрендерит нужные страницы и запишет план в `work/<имя>/plan.json`.
   Покажи мне сводку по всем файлам задачи одним сообщением и жди подтверждения.
2. **Распознавание.** Для каждой страницы из `plan.json` → `selected`, у которой ещё нет `work/<имя>/html/pNNN.html`:
   открой `work/<имя>/pages/pNNN.jpg` (и `text/pNNN.txt`, если есть) и сохрани `html/pNNN.html` по правилам из `prompts/transcribe.md`.
   - Иди по порядку, пачками по 4 страницы. Если можешь запускать субагентов, отдавай каждому пачку, чтобы картинки не копились в основном контексте.
   - Каждую картинку открывай один раз. Готовые страницы не переделывай.
   - Если работа оборвалась (лимит, ошибка), в следующей задаче продолжай с первой страницы без html-файла.
3. **Сборка.** Запусти `python tools/assemble.py "work/<имя>"`.
   Если скрипт пишет «НЕ ХВАТАЕТ страниц», распознай их и запусти снова.
4. **Отчёт.** По каждому файлу: сколько страниц распознано, путь к DOCX, число флагов в `output/<имя>_flags.md`.

## Нельзя
- Исправлять цифры, опечатки и формулировки документа. Расхождения помечай FLAG.
- Открывать картинки повторно или «для проверки», если я об этом не прошу: каждое открытие расходует лимит.
- Пропускать страницы из `selected` или добавлять страницы, которых там нет.
