# Правила распознавания страниц → HTML

Каждая страница — это картинка `work/<имя>/pages/pNNN.jpg`. Результат сохраняй в `work/<имя>/html/pNNN.html` (тот же номер).
Если есть `work/<имя>/text/pNNN.txt`, это цифровая страница. Слова и цифры бери из .txt, а структуру (таблицы, списки) — с картинки.

В файл пиши только HTML-фрагмент страницы: без пояснений, без ```, без <html>/<body>.

## Точность
- Дословно, символ в символ: цифры, пунктуация, «ёлочки», тире, ё, № — как в оригинале. Ничего не исправлять, не дополнять, не сокращать.
- Если не читается уверенно, пиши лучший вариант в `<span class="unclear">…</span>` и добавляй строку `<!-- FLAG: неразборчиво: … -->`.
- Латиницу (Breitkopf, Leipzig, Sheet music) оставляй латиницей, как в скане.

## Структура
- Номер страницы внизу, пятна и следы сканирования не выводить.
- Разделы с римскими цифрами и крупные заголовки по центру оформляй как <h1>. Жирные подзаголовки по центру — <h2>. Прочие выделенные заголовки — <h3>.
- Жирное начало абзаца («Характеристика учебного предмета…») оформляй так: <p><b>…</b> дальше текст</p>.
- Строки одного абзаца склеивай в один <p>. Перенос слова в конце строки убирай («художе-ственный» → «художественный»), настоящий дефис оставляй («художественно-образный»).
- Курсив — <i>, подчёркивание — <u>, жирный — <b>. «Таблица N» справа курсивом оформляй как <p class="caption"><i>Таблица N</i></p>.
- Маркированные списки (✓, ▪, ➢, •, «-») — <ul><li>. Нумерованные — <ol start="N">, где N — номер первого пункта на этой странице.
- Если страница начинается с продолжения абзаца с предыдущей страницы, ставь <p data-continued="true">.

## Таблицы
- Только <table>. rowspan/colspan ставь ровно как в скане. Шапка — <th>, пустая ячейка — пустой <td>, прочерк «-» — обычный текст.
- Строки-разделители на всю ширину («АНСАМБЛИ УДАРНЫХ ИНСТРУМЕНТОВ», «2 класс») делай одной ячейкой: <td colspan="(вся ширина)" align="center"><b>…</b></td>.
- Внутри ячейки отдельные смысловые строки (пункты, «1 вариант», названия пьес) разделяй <br>. Обычный перенос строки посреди фразы склеивай.
- Если таблица продолжается с предыдущей страницы (нет шапки / обрезана сверху), ставь <table data-continued="true">. Шапку не повторяй и не придумывай.
- Если первая строка на странице — продолжение строки, разорванной на предыдущей, ставь <tr data-continues-row="true">, а в ячейки пиши только продолжение текста.
- Если итог в таблице не сходится с суммой по строке, оставь как в скане и добавь <!-- FLAG: таблица: что не сходится -->. Сверх беглой проверки итогов ничего не пересчитывай.
